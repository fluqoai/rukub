# مراجعة المتجر والإدارة — 2026-09-04

## التعريب وصفحة المنتج

- وجدت مسودتين عربيتين جاهزتين للمرطب ووسادة مسند الذراع، لكن حقول المنتج ظلت إنجليزية. استعيدتا مع مطابقة المصدر والمحافظة على السعر والتكلفة والخيارات وحالة النشر، دون توليد جديد.
- العبارة التعريفية الفارغة في نتيجة الذكاء الاصطناعي كانت تُفشل التحقق من الحقول المطلوبة؛ أصبحت تستخدم الاسم العربي المختصر عند غيابها، دون اختلاق مواصفات.
- الحفظ العام أثناء فتح مسودة غير معتمدة يتوقف ويوجه إلى زر اعتماد التعريب وحفظه، بدل تجاهل المسودة وحفظ المصدر الإنجليزي.
- الوصف ظاهر قرب الشراء، مع رابط واضح إلى التفاصيل، والمحافظة على الأسطر وجميع المميزات (حتى 12) بدل قصها إلى ثلاث.
- خمس إضافات CJ أخرى لم يكن لها تعريب محفوظ. لم تُنشأ لها أوصاف تلقائية أو مواصفات غير موثقة.

## عمليات الإدارة

| القسم | التغيير والتحقق |
|---|---|
| الرئيسية | بيانات الخادم بدل سجل المتصفح؛ إزالة النمو الوهمي؛ مبالغ المسلّم فقط مع تنبيه أنها ليست إثبات تحصيل |
| الطلبات | فلاتر التجهيز والاسترداد؛ تحديث فعلي للبيانات؛ أخطاء الحالة والتتبع ظاهرة |
| تفاصيل الطلب | إصلاح تحديث التتبع دون حالة؛ فصل التتبع عن إرسال البريد؛ تأكيد قبل تغيير الحالة؛ تسجيل الاسترداد لا يحوّل أموالًا |
| المنتجات | حماية اعتماد التعريب واستعادة النصين المحفوظين؛ فحص المحتوى العام على الدومين الحقيقي |
| العملاء | اشتقاق البيانات من طلبات الخادم، لا تاريخ الجهاز؛ الإنفاق للطلبات المسلّمة |
| التحليلات | إزالة قيم التحويل وCOD والتوصيل الوهمية؛ إصلاح ارتفاع الرسم؛ توضيح نطاق البيانات |
| الشحن | عرض الحالات الفعلية مع فلتر وروابط الطلبات؛ لا ادعاء بتتبع مباشر لشركة الشحن |
| الإشعارات | سجل محاولات خادمي؛ حفظ التفضيلات فعليًا وتطبيقها في خدمة الإرسال؛ تسجيل المحاولة قبل الإرسال؛ فشل واضح عند غياب إعداد البريد |
| الإعدادات | حالة الخدمات للعرض؛ تغيير كلمة المرور مساره الحالي؛ لم تتغير كلمة المرور أو مفاتيح الخدمات أو الدفع |
| الدخول والخروج | إظهار فشل تسجيل الخروج بدل إخفائه؛ مسارات الإدارة محمية بالجلسة |

التقارير والعملاء والشحن تغطي أحدث 1000 طلب. سجل البريد يغطي أحدث 100 محاولة؛ السجلات المحلية القديمة لا تُقدّم كإثبات إرسال. قبول المزود للرسالة لا يثبت وصولها.

## الاختبار وحدوده

- 16 اختبارًا: حفظ النص العربي، مصدر التعريب، حماية VID والأسعار، الخيارات والسلة، التحقق من الطلب، تحديث التتبع دون تغيير الحالة، المدخلات المرفوضة، حماية الجلسة، وتفضيلات البريد وتسجيل المحاولة قبل الإرسال.
- فحص المتصفح للرئيسية والعملاء والتحليلات والشحن والطلبات وتفاصيل طلب موجود والإعدادات والإشعارات وصفحة المنتج؛ دون تعديل طلبات العملاء.
- حفظ تفضيلات البريد الحالية كما هي نجح، دون تغيير سياسة الإرسال أو إرسال رسالة.
- لا شراء من CJ، لا طلبات تجريبية جديدة، لا بريد حقيقي، لا استرداد مالي أو تغيير كلمة المرور أثناء التحقق. هذه العمليات تحتاج اختبار قبول منفصل ومصرح به.
- لا تغييرات على مخطط قاعدة البيانات أو صلاحياتها. استُخدمت الجداول الحالية خلف واجهات إدارة محمية.
