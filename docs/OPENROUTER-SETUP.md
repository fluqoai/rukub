# تشغيل التعريب

الإعدادات التالية خادمية فقط، تُضبط في `.env.local` محليًا وفي إعدادات مشروع ركوب على Vercel للإنتاج:

```dotenv
OPENROUTER_API_KEY=<your-server-only-key>
OPENROUTER_MODEL=qwen/qwen3.7-plus
AI_MAX_GENERATIONS=100
```

لا يُرسل المفتاح للمتصفح ولا يُحفظ في Git. يوصى باستبدال أي مفتاح سبق مشاركته في محادثة ووضع حد إنفاق له من لوحة OpenRouter.

من لوحة الإدارة: المنتجات → منتج جديد → استيراد PID من CJ → تحقق من النسخ المطلوبة → راجع اسم كل خيار وسعره وفعّله → تجهيز المحتوى بالعربية → راجع المسودة والتحذيرات → اعتماد في النموذج → احفظ المنتج.

لمنتج موجود بمورد واحد، افتح تعديله ثم «جلب خيارات CJ لهذا المنتج». تبقى الخيارات الجديدة غير مفعلة حتى التحقق. الباقات الحالية ذات عدة مكونات لا تُحوّل إلى خيارات بديلة.

الأسعار العامة للمنتج تُحسب من أرخص نسخة مفعّلة، لكن لكل نسخة سعرها وتكلفتها الخاصة. السجل يعرض تكلفة التوليد الفعلية عندما تعيدها المنصة. حاليًا لا توجد إعادة مدفوعة تلقائية للمحاولات الفاشلة؛ راجع سجلها قبل تقديم مصدر معدل.

## الاختبار

`npm test` اختبارات محلية دون اتصالات خارجية. `npm run lint` و`npm run build` للفحص والبناء.

`node --env-file=.env.local scripts/verify-catalog-live.cjs balance` قراءة الرصيد فقط.

وضع `ai` في الأداة السابقة قد يولد مسودة مدفوعة واحدة. وضع `cj` قراءة فقط دون طلب شراء.

للتحقق من الإنتاج على rukub.shop: `node --env-file=.env.local scripts/verify-production.cjs`. أضف `--ai` للسماح بمسودة اختبار واحدة مدفوعة؛ المصدر ثابت لذلك يُستخدم السجل المحفوظ عند إعادة الاختبار. الأداة لا تنشر المنتج ولا تنشئ طلبًا ولا ترسل بريدًا، وتحذف جلسة الإدارة التي تنشئها بعد الانتهاء.

متغيرا `VERCEL_TOKEN` و`DATABASE_URL` للإدارة المحلية فقط، مستبعدان من Git ولا يُرفعان إلى متغيرات تشغيل الموقع. تجنّب تشغيل سكربت إصلاح البيئة القديم الذي يحذف جميع المتغيرات؛ عدّل فقط المفاتيح المطلوبة مع الحفاظ على البقية.

اختبار HTTP المحلي يتطلب خادمًا على localhost:3000. ينشئ جلسة إدارة قصيرة وطلبًا ملغيًا للاختبار ثم يحذف الطلب وعميله، ولا يرسل بريدًا. بعد الاختبار شغّل `node --env-file=.env.local scripts/verify-catalog-http.cjs cleanup` لإلغاء الجلسة وحذف ملفها المحلي المستبعد من Git.
